One emoji, chosen to make a stranger smile. A pure-Python program that writes exactly one emoji — 🤗, a hugging face, an open-arms hug offered to a stranger — to `/output/entry.txt`, entered in make.fun's "One Emoji, One Smile" bounty. `CANDIDATES.md` records the 18 candidates considered and why the pick was revised from 🫶 to 🤗.

## Run it

```sh
python3 main.py
```
